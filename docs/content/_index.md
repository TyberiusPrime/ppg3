# ppg3

A constructive-trace build system: an input-addressed store, sandboxed
deterministic jobs, and a Python front-end for declaring the graph.

Start with the [tutorial](docs/tutorial/) for a hands-on tour, or read the
[design document]({{< relref "/" >}}) and `CONTRACT.md` in the repository for
the full picture.
