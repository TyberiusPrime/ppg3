# ppg3

A constructive-trace build system: an input-addressed store, sandboxed
deterministic jobs, and a Python front-end for declaring the graph.

Start with the [tutorial](docs/tutorial/) for a hands-on tour, look up any
`ppg3.new()`/`ppg3.run()`/job parameter in the
[API by example](docs/api/) reference (every example there is executed by
the test suite), or read the [design document]({{< relref "/" >}}) and
`CONTRACT.md` in the repository for the full picture.
